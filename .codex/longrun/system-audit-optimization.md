# 长跑状态账本：站点 / 连接 / 账号 / 网关 / 日志审计

## spec

- 任务ID：system-audit-optimization
- 目标：梳理当前站点、连接、账号、网关、日志全链路实现，并结合开源项目寻找稳定性、可用性、性能和排障能力提升点
- 范围：`src/server`、`src/web` 中与 sites/accounts/routes/proxy/logs/health/checkin/stats 直接相关的代码；外部开源项目与上游仓库的同类实现
- 约束：先审计后建议；不做无关重构；以证据为基础输出优先级建议
- 完成定义：
  - 形成当前架构梳理
  - 形成关键风险与薄弱点清单
  - 形成外部项目可吸收方案清单
  - 给出分阶段落地建议
